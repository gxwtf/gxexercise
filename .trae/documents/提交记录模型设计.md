# 提交记录模型设计方案

## 现有模型分析

当前的三级题库模型结构：

1. **Question** (单题) - 第一级，基础题目单元
2. **QuestionGroup** (题组) - 第二级，包含多个 Question
3. **TestPaper** (试卷) - 第三级，只包含 QuestionGroup

关联关系：
- `GroupItem`: 连接 QuestionGroup ↔ Question
- `PaperItem`: 连接 TestPaper ↔ QuestionGroup

---

## 提交记录模型设计

### 1. QuestionSubmission (单题提交记录)

对应 **Question** 的提交记录，记录用户对单个题目的作答。

```prisma
model QuestionSubmission {
  id          String   @id @default(cuid())
  userId      Int
  questionId  String
  content     Json?                    // 用户作答内容（JSON 格式存储用户答案）
  score       Float?                   // 得分（浮点数）
  isCorrect   Boolean?                 // 是否正确
  createdAt   DateTime @default(now())

  user        User     @relation(fields: [userId], references: [id])
  question    Question @relation(fields: [questionId], references: [id])

  @@index([userId])
  @@index([questionId])
  @@index([userId, questionId])
}
```

### 2. QuestionGroupSubmission (题组提交记录)

对应 **QuestionGroup** 的提交记录，记录用户对一个题组的作答。

```prisma
model QuestionGroupSubmission {
  id              String   @id @default(cuid())
  userId          Int
  questionGroupId String
  content         Json?                     // 题组作答内容（JSON 格式）
  score           Float?                    // 得分（浮点数）
  isCorrect       Boolean?                  // 是否完全正确
  correctNum      Int?                      // 正确题数
  totalNum        Int?                      // 总题数
  duration        Int?                      // 答题时长（秒）
  createdAt       DateTime @default(now())

  user            User         @relation(fields: [userId], references: [id])
  questionGroup   QuestionGroup @relation(fields: [questionGroupId], references: [id])
  submissions     QuestionSubmission[]      // 关联的子题目提交

  @@index([userId])
  @@index([questionGroupId])
  @@index([userId, questionGroupId])
}
```

### 3. TestPaperSubmission (试卷提交记录)

对应 **TestPaper** 的提交记录，记录用户对整份试卷的作答。

```prisma
model TestPaperSubmission {
  id              String   @id @default(cuid())
  userId          Int
  testPaperId     String
  content         Json?                     // 试卷作答内容（JSON 格式）
  score           Float?                    // 总分（浮点数）
  duration        Int?                      // 答题时长（秒）
  startedAt       DateTime?                 // 开始时间
  submittedAt     DateTime?                 // 提交时间
  createdAt       DateTime @default(now())

  user            User         @relation(fields: [userId], references: [id])
  testPaper       TestPaper    @relation(fields: [testPaperId], references: [id])
  groupSubmissions     QuestionGroupSubmission[] // 作答的题组

  @@index([userId])
  @@index([testPaperId])
  @@index([userId, testPaperId])
}
```

## 字段设计说明

### 公共字段

| 字段        | 类型        | 说明             |
| --------- | --------- | -------------- |
| id        | String    | 主键，使用 cuid     |
| userId    | Int       | 用户 ID，关联 User  |
| createdAt | DateTime  | 创建时间           |
| content   | Json?     | 作答内容（灵活存储用户答案） |
| score     | Float?    | 得分（浮点数）        |

### QuestionSubmission 专属字段

| 字段         | 类型       | 说明    |
| ---------- | -------- | ----- |
| questionId | String   | 题目 ID |
| isCorrect  | Boolean? | 是否正确  |

### QuestionGroupSubmission 专属字段

| 字段              | 类型       | 说明             |
| --------------- | -------- | -------------- |
| questionGroupId | String   | 题组 ID          |
| correctNum      | Int?     | 正确题数           |
| totalNum        | Int?     | 总题数            |
| isCorrect       | Boolean? | 是否完全正确（所有题目都对） |
| duration        | Int?     | 答题时长（秒）        |

### TestPaperSubmission 专属字段

| 字段          | 类型        | 说明    |
| ----------- | --------- | ----- |
| testPaperId | String    | 试卷 ID |
| duration    | Int?      | 答题时长  |
| startedAt   | DateTime? | 开始时间  |
| submittedAt | DateTime? | 提交时间  |

## 关系设计

```
User (1) ──────< (N) QuestionSubmission
User (1) ──────< (N) QuestionGroupSubmission
User (1) ──────< (N) TestPaperSubmission

Question (1) ──────< (N) QuestionSubmission
QuestionGroup (1) ──────< (N) QuestionGroupSubmission
TestPaper (1) ──────< (N) TestPaperSubmission

QuestionGroupSubmission (1) ──────< (N) QuestionSubmission
TestPaperSubmission (1) ──────< (N) QuestionGroupSubmission
```

## JSON Content 字段建议结构

### QuestionSubmission.content

```json
{
  "answer": "用户的答案",
  "selectedOptions": ["A", "C"],
  "extra": {}
}
```

### QuestionGroupSubmission.content

```json
{
  "answers": {
    "questionId1": "答案1",
    "questionId2": "答案2"
  },
  "extra": {}
}
```

### TestPaperSubmission.content

```json
{
  "groupAnswers": {
    "groupId1": {
      "questionId1": "答案",
      "questionId2": "答案"
    },
    "groupId2": {
      "questionId3": "答案"
    }
  },
  "extra": {}
}
```

## 实施步骤

1. **在 schema.prisma 中添加以下模型**：
   - QuestionSubmission
   - QuestionGroupSubmission
   - TestPaperSubmission

2. **更新 User 模型**，添加与提交记录的关系

3. **生成 Prisma Client**：
   ```bash
   npx prisma generate
   ```

4. **创建数据库迁移**：
   ```bash
   npx prisma migrate dev --name add_submission_models
   ```

5. **（可选）创建相关 Service/API 层代码**
