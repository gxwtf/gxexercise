根据以下信息评阅学生的作答，只输出 JSON：

【题目】{stem}
【参考答案】{correctAnswer}（开放性问题，言之有理即可；学生观点与参考答案不同但合理，同样算切题）
【学生作答】{userAnswer}
【本题满分】{maxScore} 分（内容 2 分 + 语言 2 分 + 结构 1 分）

【本题形态】要求学生用英文写「一个完整的段落」回答，题目只要求约 40 词。

【一、内容（满分 2 分）】
- 2 分：观点明确、直接回答问题，并且给出理由或支撑；与参考答案方向一致，或自圆其说、逻辑成立。
- 1.5 分：观点清楚、有理由，但支撑略单薄，或有一处小的偏离。
- 1 分：观点基本清楚，但理由空泛（只有套话）、或只答了一半。
- 0.5 分：观点含糊、只表态不解释，或与题目相关性弱。
- 0 分：离题、答非所问、抄题干、或完全空泛。
- 另有扣分项：明显过短（不足 28 词，约为要求词数的 70%）或内容残缺，在内容维度扣分，最多扣 1 分。

【二、语言（满分 2 分）】
- 2 分：用词准确、句式有变化，基本没有影响理解的错误。
- 1.5 分：有少量语法 / 拼写 / 搭配错误，但不影响理解。
- 1 分：错误较多，个别地方影响理解。
- 0.5 分：错误密集，多处影响理解。
- 0 分：几乎读不懂、大面积中式英语，或只有零散单词。

【三、结构（满分 1 分）—— 必须是一个完整段落】
- 1 分：整段就是一个完整段落：句子完整（主谓齐全、没有被截断），句间有自然衔接（because / for example / also / so / which 等），有头有尾。
- 0.5 分：段落基本成立，但有明显结构问题：第一句不完整（半句、缺主语或谓语、写到一半断掉）、或句与句之间缺少衔接。
- 0 分：不成段落：只给几个词或一个短语、通篇断句、或把答案写成几条互不衔接的独立短句。
  例如「Yes. Because hobbies are fun. Pure enjoyment. So yes.」这种一条一断、彼此没有衔接的写法 → 结构 0 分。

【硬性要求】
- 每个维度只允许给 0.5 的整数倍（0、0.5、1、1.5、2），不要出现 0.25、0.75 这类分数。
- 三个维度之和就是本题得分，最高 {maxScore} 分，最低 0 分，不得为负。
- 超字数不扣分：题目只是「约 40 词」，写到 60～80 词甚至更多，只要内容不空泛、语言通顺连贯就不扣分；也不要因为写得多而在评语里表扬字数。
- 评语（feedback）用中文，按「内容 / 语言 / 结构」逐条说清扣在哪里、为什么；满分时为空字符串。

【输出格式】只输出一个 JSON 对象：
{"subScores":{"内容":<数字>,"语言":<数字>,"结构":<数字>},"feedback":"<中文点评>"}

立即输出 JSON，不要输出任何其他内容。
