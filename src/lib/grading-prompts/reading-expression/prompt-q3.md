根据以下信息评阅学生的作答，只输出 JSON：

【题目】{stem}
【参考答案】{correctAnswer}
【学生作答】{userAnswer}
【本题满分】{maxScore} 分 = 划线 1 分 + 修改 2 分

【作答格式】学生作答的第一行是他「划线」的部分，也就是他判断错在哪里；从第二行开始是修改 / 解释。

【划线判分（1 分）】
- 得 1 分：划出的部分与参考答案指明的错误部分一致，并且是一个「完整的 chunk」（一个完整的意群：短语、从句或分句），不多划也不少划。
- 得 0 分：划错位置；只划了 chunk 里的一个词或半个短语（不完整）；把正确部分也一起划进来；或根本没有划线。
- 参考答案里有的明确写出了划线位置，有的没写，但解释部分已经能体现错误位置——以解释为准。
- 划线错误不影响修改部分的判分，仍然继续判修改（海淀标准）。

【修改判分（2 分，三档）】
- 2 分：把错误部分改成了与原文 / 参考解释一致的正确内容。意思对即可，不要求和参考答案文字一模一样；学生用自己的话解释正确同样给 2 分。
- 1 分：只改对了一部分，或意思基本对但不完整、表达含糊。
- 0 分：没有改对、只是把原文的错误重复一遍、或根本没给修改。
【修改的冗余扣分】修改里夹带与「把错误处改正」无关的多余内容（重复题干、无关补充、长篇额外解释），每处从修改分里扣 0.5 分，修改分最低 0 分。
【语言扣分】修改部分明显的语法 / 拼写 / 时态错误，每处扣 0.5 分，本题因语言错误最多扣 1 分。

【总分】划线分 + 修改分 − 语言扣分；最低 0 分，不得为负。

【注意】
- 只输出结构化判断（underline / underlineCorrect / underlineComplete / fixLevel / redundant / grammarErrors / feedback），不要自己给分；
- 学生划线正确、修改也完全正确时为满分，此时 feedback 为空字符串。

立即输出 JSON，不要输出任何其他内容。
